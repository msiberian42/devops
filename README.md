# devops
Практическое задание с самопроверкой "Введение в виртуализацию. Типы и функции гипервизоров. Обзор рынка вендоров и областей применения"

Задача 2
Высоконагруженная база данных MySql, критичная к отказу:
Кластер физических серверов. В такой схеме есть балансировщик нагрузки, распределяющий запросы между серверами базы данных. Каждый сервер БД дублирует у себя все данные, таким образом выход из строя одной машины не приводит к поломке всего сервиса. Такая схема наиболее производительна.

Различные web-приложения:
Паравиртуализация либо виртуализация уровня ОС (контейнеры). Паравиртуализация это более производительный вариант, однако контейнеры проще масштабировать и это более экономное использование ресурсов железа, так как не требуется прослойка в виде аппаратной эмуляции.

Windows-системы для использования бухгалтерским отделом:
Паравиртуализация. Можно развернуть виртуальную машину на windows под каждый сервис, если это требуется. Это более экономный вариант, чем отдельные физические сервера. ВМ можно бэкапировать или перемещать между хостами для распределения нагрузки. Вариант с контейнерами не подходит, так как они не позволяют развернуть полноценную windows-среду

Системы, выполняющие высокопроизводительные расчёты на GPU.
Кластер физических расчетных серверов. Для скорости расчетов солверу требуется прямой доступ к GPU. Кластер через планировщик задач распределяет расчеты между серверами.

Задача 3
1. 100 виртуальных машин на базе Linux и Windows, общие задачи, нет особых требований. Преимущественно Windows based-инфраструктура, требуется реализация программных балансировщиков нагрузки, репликации данных и автоматизированного механизма создания резервных копий.

VMware - популярное на рынке решение, подходящее под крупные инфраструктуры.

2. Требуется наиболее производительное бесплатное open source-решение для виртуализации небольшой (20-30 серверов) инфраструктуры на базе Linux и Windows виртуальных машин.

Proxmox - бесплатный и высокопроизводительный инструмент управления ВМ.

3. Необходимо бесплатное, максимально совместимое и производительное решение для виртуализации Windows-инфраструктуры.

Hyper-V - бесплатное и максимально совместимое с Windows решение

4. Необходимо рабочее окружение для тестирования программного продукта на нескольких дистрибутивах Linux.

Oracle VirtualBox - бесплатный инструмент управления ВМ. Можно быстро создавать и удалять ВМ, делать снапшоты, монтировать образы ВМ под конкретные нужды

Задача 4

Гетерогенная среда виртуализации несет следующие издержки:
1. Более сложное администрирование, бэкапирование, мониторинг, обновление
2. Требуется более квалифицированный персонал, умеющий работать со всеми средами виртуализации

В каких-то случаях использование разных сред виртуализации под разные задачи может быть выгодно, особенно в крупных компаниях. В большинстве случаев более оправданно стремиться к использованию одной среды.
